# مخرطة القحطاني — النسخة متعددة الصفحات

## محتويات المشروع
- `index.html`: الصفحة الرئيسية بالتصميم الأصلي المحسّن.
- `services.html`: دليل الخدمات.
- `turning.html`: شرح الخراطة التقليدية.
- `cnc.html`: شرح خراطة CNC.
- `laser.html`: شرح القص بالليزر.
- `gallery.html`: معرض صور توضيحي.
- `about.html`: صفحة تعريفية.
- `contact.html`: نموذج يجهز رسالة واتساب ولا يحفظ بيانات الطلب.
- `app.py`: خادم Python وربط المساعد الذكي.

## التشغيل محليًا
1. ثبّت Python 3.10 أو أحدث.
2. أنشئ بيئة افتراضية:
   `py -m venv .venv`
3. فعّلها في PowerShell:
   ` .\.venv\Scripts\Activate.ps1 `
4. ثبّت المتطلبات:
   `pip install -r requirements.txt`
5. انسخ `.env.example` إلى `.env` وأضف مفتاح API صالحًا إذا أردت تشغيل المساعد الذكي.
6. شغّل `python app.py` وافتح `http://127.0.0.1:5000`.

ملاحظة: صور الصفحات من الإنترنت وتحتاج اتصالًا. الصور أمثلة توضيحية وليست إثباتًا لوجود معدات أو أعمال بعينها لدى المخرطة. لا ترفع ملف `.env` أو مفتاح API إلى Git أو إلى الواجهة الأمامية.
